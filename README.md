# Kvadrat.rs

Interaktivni preview sajta za nekretnine: pretraga oglasa, galerija, mapa cena i kreditni kalkulator.

- `index.html` — stranica i stilovi
- `app.js` — logika aplikacije
- `data.js` — podaci o oglasima (`window.KV`)

Pokretanje: otvorite `index.html` u browseru (ili `python3 -m http.server` pa http://localhost:8000).
